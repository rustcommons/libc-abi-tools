# ELF metadata evidence

`libc-abi glibc elf --input FILE` reads defined nonlocal dynamic symbols directly
from an ELF64 little-endian x86_64 shared library. It works on Windows and Linux
without invoking binutils or adding Rust dependencies. It never loads or executes
the input library.

The reader follows the [System V symbol table specification](https://gabi.xinuos.com/v42/elf/05-symtab.html)
and GNU version-definition layouts documented in
[glibc 2.17's ELF declarations](https://github.com/bminor/glibc/blob/c758a6861537815c759cba2018a3b1abb1943842/elf/elf.h).
The [GNU linker versioning documentation](https://sourceware.org/binutils/docs/ld/VERSION.html)
explains default and nondefault versions. The implementation is original Rust;
no upstream parser source was copied.

## Output

TSV rows sort lexically by symbol name and version and contain:

| Column | Meaning |
| --- | --- |
| `soname` | Library identity recorded by `DT_SONAME` |
| `symbol`, `version` | Dynamic symbol name and GNU version; `-` for unversioned |
| `default` | `yes` for a default GNU version, `no` for a nondefault version, `-` for unversioned |
| `type` | `FUNC`, `IFUNC`, `OBJECT`, `TLS`, `NOTYPE`, or an explicit numeric unknown type |
| `binding` | `GLOBAL`, `WEAK`, or `GNU_UNIQUE` |
| `visibility` | `DEFAULT`, `INTERNAL`, `HIDDEN`, or `PROTECTED` |
| `section`, `value`, `size` | Raw ELF section index, value, and 64-bit byte size |
| `section_alignment` | Declared alignment of the defining section; zero for special indexes |
| `same_range` | File-local group for matching section/value/type/nonzero-size tuples, or `-` |

Undefined imports, local symbols, and absolute version-node markers are omitted.
`GLIBC_PRIVATE`, other namespaces, and unversioned definitions are retained as
evidence. GNU version hiding is separate from ELF symbol visibility. A `default`
value does not assert that a hidden/internal symbol is publicly linkable.

`same_range` is an observation within one binary, not a directed or semantic alias
relationship. IFUNC values describe resolvers, and TLS values are TLS offsets.
Groups cannot be compared by ID across libraries/builds. Source evidence remains
necessary before deciding which aliases a complete generator must preserve.

SONAME does not establish release, authenticity, or provenance. The command does
not infer a glibc release from symbol versions. A library can export historical
versions and can include distribution-specific changes.

## Bounds and supported inputs

The reader requires section tables, dynamic symbols, a dynamic section, SONAME,
and consistent GNU version tables when present. Ordinary section numbering is
supported; extended indexes, sectionless files, other architectures/classes,
and unsupported binding/visibility bits fail explicitly. Names must be printable
ASCII with at most 1024 bytes. Limits are 64 MiB per file, 100000 dynamic symbols,
4096 version definitions, 256 auxiliary entries per definition, 1 MiB of processed
version-name data, and 8 MiB of retained symbol/version names.

Relevant tables, links, entry sizes, string termination, version chains, duplicate
definitions, and default-version uniqueness are checked. The reader does not
validate executable code, relocations, loader behavior, or symbol storage ranges;
it preserves 64-bit size/value evidence without reading that storage.

The schema is an initial inspection format, not the finalized cargo-libc artifact
contract. No general linker libraries are generated by this command.

## Qualified evidence

The two glibc 2.17 input trees from the C experiment provide eight libraries each.
Run with Cargo on PATH:

```sh
bash examples/glibc-two-paths/elf-and-check.sh /tmp/libc-abi-two-paths-clean
```

This writes metadata, raw GNU readelf output, SHA-256/provenance manifests, and
pinned ABI comparisons to `elf-metadata` within the experiment directory.
Collection overwrites its reports when rerun. The comparison normalizes GNU type
10 to IFUNC even where readelf prints `<OS specific>: 10` for old System V OSABI
files. It compares definitions, versions/defaults, types, bindings, visibility,
section/value/alignment, and sizes; public numeric GLIBC exports are compared separately
with the pinned 2.17 ABI snapshot, mapping IFUNC to its abilist function kind.

On 2026-10-09 all 6035 definitions across the 16 files matched readelf. There were
zero pinned public ABI membership/kind/object-size differences. Private exports
and code layouts differ between the distribution and upstream builds, so their
metadata and hashes remain separate. This qualifies the collector on these files,
not other releases or semantic aliases.

The original GNU-binutils fixture in `tests/fixtures/elf` additionally tests
multi-version functions, protected weak symbols, IFUNC, TLS/object sizes, imports,
and shared ranges. Its committed binary is portable input for Rust tests.
Malformed-table mutations and every byte truncation are tested without panics.

The minimal two-function generator now requires a real reference libc and
derives its bindings from this reader. It rejects missing, nondefault, ambiguous,
IFUNC, or unsupported-visibility evidence rather than guessing. Both real input
routes still pass the link/run and newer-API rejection checks. This generator
is still an ordinary-function example. A separate
[expanded emitter](STUB-GENERATION.md) now exercises selected multi-version,
IFUNC, object, and TLS exports; complete libraries and other releases remain open.
